# Hello Skill

A minimal user-defined AI skill that confirms skill discovery and invocation by responding with a fixed greeting.

## Behavior

When invoked, the skill says:

> Hello from your AI enabled skill!

## Usage

Ask your AI agent to use `hello-skill`, for example:

```text
/hello-skill
```

or

```text
Use hello-skill.
```

## Structure

- [`SKILL.md`](./SKILL.md) contains the skill metadata and invocation instructions.
- [`README.md`](./README.md) documents the skill for people browsing this repository.
